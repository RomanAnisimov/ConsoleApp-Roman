# ConsoleApp-Roman

Учебный проект по C#. Консольное приложение с меню из 6 задач.

## Что реализовано
1. Калькулятор (+ - * /)
2. Чётное/нечётное
3. Таблица умножения
4. Сумма 1..N (цикл + формула)
5. Работа с массивом (min/max/avg)
6. Mini-ToDo (List<string>)

## Как запустить
\`\`\`
dotnet run
\`\`\`
