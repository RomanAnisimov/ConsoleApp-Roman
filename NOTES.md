value type - хранятся в стеке.
reference type - хранятся в куче.

при присвоении value type происходит копирование
при присвоении reference type происходит перекидование ссылки.

------

class - ссылочный тип
struct - value type

для ускорения может использоваться struct (если он маленький), поскольку не аллокаций и меньше обращений к GC.
но class может быть и быстрее, если нужно выполнить несколько операций в коллекции, то перекидывание ссылок может быть быстрее, чкм копирование.

! string - ссылочная тип, но поведение как у Value Type (копирование, а не перекидывание ссылки.)

------

массив - коллекция с заданным размером.
List<T> позволяет менять размер коллекции.

-----

foreach - для перебора LINQ
for - для перебора массива когда нужен индекс и / или нужно поменять значения массива при переборе.

-----

null - отсутвие сслыки (присвоения)
Nullable<T> - обертка на value type. На пример, int?
?. - позволяет не обратиться к null, если слева null. То есть, если слева элемент null, то возвращаем null.
Также есть .HasValue - проверка, что элемент не null.
.Value - само значение.
